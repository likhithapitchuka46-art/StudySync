# StudySync – Gamified Study Planner

StudySync is a web-based study planner designed to help students organize, manage, and track their daily study tasks.

## Features

- Add study tasks
- Edit and delete tasks
- Mark tasks as completed
- Track daily study progress
- Study Coins for gamification
- REST API for task management
- SQLite database integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Python Flask
- SQLite

## Project Structure

- `index.html` – Frontend structure
- `style.css` – Styling
- `script.js` – Frontend functionality
- `backend/app.py` – Flask backend and REST API

## How to Run

1. Install Python and Flask.
2. Open the backend folder.
3. Run the Flask application.
4. Open the frontend in a browser.
